# automaFIT Lab

Repositorio de laboratorio reservado para prototipos de automaFIT. Todavía no hay páginas HTML ni aplicación montada.

El Editor Visual de Lab se incorpora como componente reutilizable; no se habilitará en producción ni publicará contenido ficticio hasta definir las páginas del laboratorio.


## Visual Lab Editor (13-11-2026)

El módulo de edición visual compartido está incorporado en `assets/editor/` para textos, imágenes, notas y exportación Codex/JSON/HTML, con borradores almacenados únicamente en el navegador. **Todavía no hay páginas del laboratorio en este repositorio**; la integración del script y el dominio autorizado se configurarán cuando exista una página y se confirme el control de acceso del lab. No existe publicación automática ni backend de edición. [Instrucciones y limitaciones](docs/visual-lab-editor.md).
